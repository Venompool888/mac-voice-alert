## 我不在电脑边时 = 用语音提醒

用户常常待命、人不在屏幕前。需要他注意时，除了回消息，**还要出声**（后台播放，立即返回）。

三条硬判据（中一条就出声）：
1. 要用户动手才能继续 —— 验证码、扫码、点授权、要拍板；
2. 等了一阵才有结果的事结束了 —— 超过 2 分钟的任务、后台任务完成或失败；
3. 卡住了自己搞不定 —— 报错、权限不够。

不出声：普通问答、一分钟内能回完的；中途刷进度（除非 10 分钟没动静）；同一件事喊过且状态没变；用户说过别出声。

待命模式：用户说「待命 / 帮我盯着 / 我去吃饭」→ `~/.dsh/bin/voice-alert watch on`（默认 4 小时）；
说「我回来了」→ `watch off`。没开待命时，只有判据 1、3 出声。

| 情况 | 命令 |
| --- | --- |
| 长任务开工 | `--style progress "在跑全量测试，约十分钟"` |
| 长任务结束 | `--style done "测试跑完，全部通过"` |
| 要验证码 | `--code 483921` |
| 卡住/要拍板 | `--style urgent "部署失败，要不要回滚"` |

约定：
- 一句话讲清「在做什么 + 结果 + 要你做什么」，20 字以内；不念代码、路径、URL。
- 同一件事只提示一次；用户回话后 `~/.dsh/bin/voice-alert stop`。
- 验证码一律用 `--code`（逐位慢读）。
